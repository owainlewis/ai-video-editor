This GitHub repo turns Claude Code into an entire company. It's called The Agency.

Over 230 AI agents, across 18 divisions. Engineering, design, sales, marketing, even finance. And it's already passed 160,000 stars.

Each agent is a markdown file, with its own role, rules and personality.

Need cold emails? The Outbound Strategist writes them from real buying signals, not volume.

Need to ship a feature? The Agents Orchestrator runs the whole pipeline. Planning, architecture, a dev and QA loop, then final integration. No phase moves on until it passes QA.

It's free, MIT licensed, and one script installs it into Claude Code.
