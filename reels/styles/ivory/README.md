# Ivory

## Overview

The house style, and the only one registered. Components render with these tokens. The cards are Blueprint's under new ids.

## Interface

- `style.ts:ivory`: the `StyleDef`, imported by `styles/index.ts`. Its 37 cards map `blueprint.cards`, changing only the id prefix to `ivory.`.
- `tokens.ts:tokens`: colours, fonts, type voice, spacing, grid, motion and `look`. Imported by `src/style.ts` as the active `style`. Type `Tokens`.
- `tokens.look`: `captions: "keyword"`, `chapter: "stack"`, `chart: "bare"`.
- `style.json`: generated by `npm run reel -- styles --write`.
- `DESIGN.md`: the spec.

## Invariants

- Blueprint is the only source of cards. Change them in `styles/blueprint/style.ts`.
- The id rewrite depends on Blueprint's ids starting with `blueprint.`.
- `tokens` must satisfy `StyleTokens`.
- Tests pin the palette: canvas and light bg `#F4F1EA`, ink `#1A2622`, accent `#213B34`, dark bg `#192E28`, dark ink `#F7F3EC`, dark accent `#B7CDBF`, dark accentText `#E9EFEA`, and no light shadow.
- Tests pin the type voice: `type.display.family` equals `font.sans`, weight 700, and `type.accent` is `italic`.
- The card layout tests measure text with this style's `font.minSize`, `font.labelMin`, `font.sansWidth` and `font.labelWidth`.
- After a card or summary change, run `npm run reel -- styles --write`. Tests compare `styles/registry.json` with `registry()`.
- `DESIGN.md` and the `fonts` text in `style.ts` drift from the tokens in places (card padding, display weight). The tokens are the truth.
- `DESIGN.md` says both that a caption's accent word changes colour only and that it is set in Signifier italic. `src/Captions.tsx` changes colour only.

## Side Effects

None from the code here. The style lab and `reel styles feedback` create or rewrite `review.json` here (`review/styles.ts`).

## Verification

- Run: `cd reels && npm test` (`tests/catalog.test.ts`, `tests/style.test.ts`)
- Run: `cd reels && npm run typecheck`
